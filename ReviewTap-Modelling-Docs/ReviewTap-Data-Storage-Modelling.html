How the Drawers Link Together

Everything hangs off the business — delete a business and its whole drawer set goes with it.

  • One business → many logins, plans, staff, QRs, visits, scans, ratings, reviews, feedback, AI usage, attendance, and the whole complaints section.
  • One staff member → many QRs, visits, scans, ratings, reviews, feedback entries.
  • One visit → many scans, ratings, reviews, feedback entries, AI usage rows.
  • One spot → many spot QRs and complaints. One spot QR → many complaints.
  • One complaint → many option picks and private notes. One option → many picks.
  • One business → one complaint-page settings row.

Safety Rules — What Happens on Delete

Two behaviors, chosen so history is never lost by accident.

Full cleanup (business, visit, complaint deleted)Everything underneath is deleted too — e.g. deleting a complaint also deletes its private notes and option picks.
Keep history (staff, table, QR, option deleted)The link is emptied but the records stay — e.g. deleting “Table 12” keeps its old complaints readable via the saved table-name copy. Same for renamed options and switched-off QRs.
Copies, not just linksEach complaint saves its own copy of the table name and option names at submit time — later renames can never rewrite history.
Secret codes, generated imagesVisit codes and QR secret codes are auto-generated and unique. QR pictures are drawn fresh on screen from the web address — nothing image-like is stored, so setting changes never need a reprint.

Where the Database Lives + Push Rules

Same blueprint, two homes. Standing rule: always say which home needs the push.

  • Local (testing): MySQL in Docker on this computer. Command: npx prisma db push with the address pointed at localhost:3306. Run it and confirm “already in sync”.
  • Production (live site): Cloud SQL reached via Firebase App Hosting. App Hosting does not push the blueprint by itself — run it manually through the Cloud SQL Auth Proxy (port 3307), then redeploy the site.
  • Retention: only attendance is auto-cleaned (older than 6 months). Everything else is kept until someone deletes it on screen.
