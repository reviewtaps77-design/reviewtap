Building Layers — How the Pieces Stack

Top to bottom: what you see → what does the work → where info is saved.

1 · Pages (what you see)Marketing site, customer pages, owner dashboard, admin area — plain-English screens in the Web Address Map below
▼buttons and forms call…
2 · Work-doers (server actions + web services)Save attendance, create QRs, submit complaints, AI writing, photo upload — each form on screen calls exactly one work-doer (see Button Map in the Requirements doc)
▼checked by…
3 · GatekeepersLogin check (who are you?) + role check (owner or admin?) + business check (only your own data) — applied on every protected page and work-doer
▼routed by…
4 · Address router (middleware)Reads the web address and decides: marketing page, customer page (which business?), owner/admin page, or public complaint link — adds small security headers to every response
▼
5a · Database (MySQL)13 tables — accounts, businesses, staff, QRs, visits, ratings, reviews, feedback, complaints, attendance (full field list in the Data doc)
5b · Outside helpersGoogle (posted reviews) · AI helper (review drafts) · Email service (mails) · Firebase (business photos + visit stats)

Reusable Building Blocks — Used on Many Pages

Shared pieces so every page looks and behaves the same.

SubmitButtonEvery Save/Update/Delete button: spins + disables itself while work runs
AutoRefreshOnIdleWatches the whole site; reloads data after 30 seconds of no touching
AttendanceCalendarMonth grid with color-coded days, staff picker, prev/next month
ComplaintFormMulti-pick option chips, optional description box, thank-you state
DashboardMobileNav / AdminMobileNav3-dot button → slide-in side menu on phones (all sections)
BusinessImageUploadLogo/cover picker: shrinks photos, shows upload %, saves to photo storage
FirebaseProviderQuietly starts visit statistics (optional, never blocks pages)
UI kit (button, card, input, badge, table…)Same rounded, soft-color look on every screen
StarRating, StatCard, EmptyStateStar picker, dashboard number tiles, friendly “nothing here yet” boxes
